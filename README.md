# 雅思阅读题型与解题方法

双击 index.html 即可本地使用。网站直接读取同目录的脚本和 assets 里的原题截图。

## 用 GitHub Pages 发布

1. 新建一个公开仓库。把本文件夹内的全部文件和 assets 目录上传到 main 分支，让 index.html 位于仓库根目录。
2. 打开仓库的 Settings → Pages。在 Build and deployment 的 Source 下选择 Deploy from a branch。
3. 选择 main 和 /(root)，点击 Save。部署完成后，回到 Pages 点击 Visit site。把这个网址分享给学生。

[GitHub Pages 发布源设置](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
